# 机制页必须画出那个东西

教学机制页要让眼睛看见对象，不能只给它起名。口语 / chrome 禁令仍有效，见 [humanize-classroom.md](humanize-classroom.md)。坐标轴仍不能当机制主角，见 [ppt-visual.md](ppt-visual.md) 禁止条。

## 画出对象，不要只点名

| 对象 | 页上必须是 | 不是 |
|------|------------|------|
| 搜索分布（CMA 等） | 重叠 / 倾斜的淡彩椭圆，像一团「椭圆状的云」 | μ σ C 彩胶囊代替云；自制坐标轴当主角 |
| 架构（T5、Transformer、encoder-decoder） | 结构图：有名字的盒子 + 细直线连接，资料流从左到右或从下到上 | 层名子弹列表 |
| 对比（六点 vs 三个参数） | **点和云在同一页**，眼睛自己做 12 对 6 | 两列说明文字 |

图用 matplotlib / PIL 出 PNG，或用原生形状真的画成那个物件。彩色字胶囊不是图。

轴如果要有，只做淡底，不当故事。云才是图。

## 禁止公式墙

一页几乎全是叠起来的式子、没有图 → 拆开。一页一个机制：图 + 当场一笔数。公式坐在对应的图旁边，不代替图。

Hansen 风格 CMA，四张图就是这堂课：

| 步 | 图 | 公式放哪 |
|----|----|----------|
| 采样 | 点从云里出来 | 云旁边 |
| 均值更新 | 云的圆心在挪 | 云旁边 |
| σ | 云在缩小 / 变大 | 云旁边 |
| C | 云在倾斜 | 云旁边 |

反例（描述，不入库）：「核心公式」墙——采样 / 评估排序 / 更新 / 步长启发式四段字，页上没有分布的样子。学不会。

## 禁止死白

教学机制页底边 **25% 以上空着**是失败。要么图长进那块空，要么盒子缩到贴住内容（不要 2.45 寸高的盒子只装三行）。

反例（描述，不入库）：

- 六点 vs μσC 页：内容挤在上半，底边约 40% 空白。右列「下一拍只带这些」是导播腔，本来就不该写。
- σ CSA 页：两个巨大淡彩盒，算术浮在盒的上半，每个盒底空掉三分之一。标题是主张，但没有缩小的云。

对面的失败：字墙、没有气口。拆页，不要缩字号。

封面 / 仪式 / 议程稀疏拍可以疏。这条打的是**该有图的教学页**把图省掉、把盒子撑大。

## 数字在芯片正中，不要贴地板

淡彩芯片里，字母 + 说明作为一组**垂直居中**。灰色二次标签（`n=2 个数`）不要掉到盒底边。

标签 bbox 吻上另一个形状仍是失败（见 [anti-patterns.md](anti-patterns.md)）。芯片内基线错位的数字同样失败。
