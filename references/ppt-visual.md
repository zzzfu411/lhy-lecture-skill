# 视觉规范

对照 2025 原件（`05-BasicML` 84 页、`06-TrainingTip` 83 页、`00-LLM-intro`、`03-LLMunderstand`）得出。他的页是**画出来的一张图**：淡彩圆角块或角色 + 箭头 + 浮动演算，不是填满的工作表，不是卡片盘，不是纯口号。

## 画布

| 年代 | 尺寸 | 内容底 | 默认标题页 |
|------|------|--------|------------|
| 2025 / 2024 默认生成 | 13.333" × 7.5"（16:9） | 白 `#FFFFFF` | 纯黑 `#000000`，见下 |
| 2021 经典（用户点名才切） | 10" × 7.5"（4:3） | 白 | 黑底 + 细橙框；不要和 2025 品牌句混用 |

页边 0.45"。无页眉 Logo、无每页课程名、无底栏。

三种年份是**不同产品**。默认生成器只走 2025。不要混进：

- 2024：满版 AI 图封面 + 橙色姓名条
- 2021：4:3 Calibri 英文 + 青绿科技图 / 模糊代码底

## 标题页（2025 品牌）

默认封面对照 `00-LLM-intro` p1、`03-LLMunderstand` p1。只凭这一节就该能画出那张封面。

```
满版纯黑 #000000
2–4 行超大白字（微軟正黑體），课题也是白的：

  一堂课搞懂 / 看懂
  〔课题〕
  的原理 / 的概念

右下 byline：黄 #FFD400（原件是「李宏毅」；换课题写成这门课的署名）
```

黄**只**给署名。不要把课题涂黄。

| 变体 | 何时用 | 对照 |
|------|--------|------|
| **默认** | 生成器一律先走这条 | 黑底、标题全白、只有署名黄 |
| **B** | 课题是一对要点亮的词 | `05-BasicML` p2：黄只涂「機器學習和深度學習」，「一堂課搞懂 / 的基本概念」仍白。底可以是黑或深蓝设计底 |
| **C**（稀有） | 用户点名「广告封面 / designed cover」 | `06-TrainingTip` p1：橙→紫渐变 + `+` `o` `.`，标题全白。不要当默认 |

可选第 0 页（课堂仪式，不是后勤）：黑底，白字「请各位同学稍待片刻」，黄字开课时间。对照 `05-BasicML` p1。

可选收尾：黑底 + 二维码 + Colab URL + 左侧和底边一条细橙 L 框（部分 2025 收尾、`07-LLMtraining` 标题也见过）。这是 closer，不是默认封面，也不是空白末页。

## 机制页的构图语言

2025 机制页有两条金线，贴纸不是必选项。

### 更常见：淡彩圆角块（`05-BasicML` p42）

三列胖圆角块当表头（浅蓝 / 浅黄 / 浅桃），中间灰 `+`、灰块箭头，**块下直接写算出来的数**（`L=240`、`y=1.67x₁+4.85`、`w₁*=1.67 / b*=4.85`）。w 蓝 b 红。零贴纸。留白很多。一页一个念头。

议程同构：竖叠 2–5 个彩胶囊，红内描边点亮当前步（`03-LLMunderstand` p5）。也是零贴纸。

### 有时：贴纸资料流（`05-BasicML` p5 / p11 / p14）

只在需要具象样本走 `x → f → y` 时用。角色类型 ≤3；同一资料图标可重复 3 次，**不同例子要重着色**（橙 / 绿 / 蓝），不要「生成时直接同色」。

1. **角色可选用真贴图，但不是每页都要。** 模型 = `assets/robot-f.png` 或大浅蓝圆角框 + 斜体 *f*；一笔资料 = `assets/ppt-file.png`。优先级：素材库贴图 > emoji > 组合形状。禁止机制页**全部**角色都是无脸灰盒。也禁止一页贴纸游行（手电筒 + 文件夹 + 旗 + 标签同时上场）。BBO L01 s08 那种路径代价全图、角色过多，过密。
2. **数字浮动，不进资料表。** 演算写成数学式：贴在箭头旁（p11：`(99−100)² = 1` 进点线演算列），或写在淡彩块正下方（p42）。**禁止把 Loss / 资料行装进表格。**
3. **两种箭头。** 实线粗黑 = 资料流（x → f → y）。点线 = 旁白。垂直点线从下方指上来提问，是他的招牌。步骤页用灰色加号 / 块箭头。
4. **公式逐项上色。** `y = w₁x₁ + b`：w 蓝 `#0070C0`、b 红 `#FF0000`、其余黑。第一个模型式子用**红点线框**圈住，旁边红字注释（`出自人类对于任务的理解`）、蓝字标签（`模型 (Model)`）。公式用 Cambria Math 斜体。
5. **从图标虚线往下拆特征（`05-BasicML` p16）。** 顶上一行贴纸流（文件 → 机器人 → 输出）。从文件图标垂直**虚线向下**，旁注「函数的输入只能是数字」，下列 `x₁…x₄`。右侧才是红点线框公式和更复杂的候选式。这是公式页的显式版式，不要改成无来源的子弹列表。
6. **文字有颜色语义。** 蓝字 = 该做什么 / 指模型。红字 = 关键 / 警告。黑字 = 陈述。

### 回忆页可以用无脸色块

回想抽象 IO 管线时，输入 / 输出 / 标准答案用彩色圆角块即可（`05-BasicML` p9）。色块禁令只打「主隐喻页上每个角色都是灰盒」。

### 表格：禁的是资料表，不是提问模板

- **仍禁：** 把机制的资料行、Loss 行、预测 vs 实际放进 `addTable`。金标准是 p11 浮动演算或 p42 盒下算式。
- **例外：** 空的 / 省略号「提问模板表」可以——列表头就是要学生问自己的问题。对照 `06-TrainingTip` p3：方法名 / 改了哪一个步骤 / 带来什么好处；红圆角框圈住要紧的那一列；格子里是 `……`，不要填一表数字。下面可以再接 3+1 步骤块。
- 课程规划表仍可（原型 B）。

## 密度（疏 ≠ 空，也 ≠ 塞满）

「约 40 字」是防空页的地板，不是目标。抽样中位：2025 BasicML ~47 个 CJK 字/页，TrainingTip ~87，LLMunderstand ~70。

| 页类 | 页上应有 |
|------|----------|
| 机制页 | 一个念头 + 完整零件（常是 2–5 个淡彩块，或一条资料流）+ 至少一笔算出来的数。三盒一页就够。不要要求 10–25 个形状 |
| 揭示页 | 同一张图做三种合法递增之一（见下） |
| 问句钩 | 问句 + 半条资料流 / 点线缺口 / 教室场景漫画。禁止只有标题，禁止风景图 |
| 步骤 / 议程 | 2–5 个低饱和圆角块 + 灰加号或块箭头 + 红内描边点亮其一 + 底部一句人话（可无） |

宁可留白，不要把整条 path-cost 塞进一页。只有标题的页仍失败。底部允许一整句黑字注释。

原件机制页通常 1–3 种角色；截图 / 迷因 / 证据图页可以很「多媒体」（`05-BasicML.pptx` 嵌约 350 个媒体）。公开仓不发行那些原件媒体。

## 字体与字号

默认 CJK 是**微軟正黑體**（theme 写 Aptos 没关系，正文仍用正黑）。用户写简体就出简体，不要改繁。

| 用途 | 字体 | 字号 |
|------|------|------|
| 标题 | 微軟正黑體 / 微软雅黑 | 28–36pt（封面行可更大） |
| 正文 / 盒内 | 同上 | 16–22pt |
| 公式与变量 | Cambria Math 斜体 | 20–40pt，宁大 |
| 浮动数字演算 | Cambria Math | 16–24pt |
| 底部注释 | 微軟正黑體 | 16–20pt |
| 脚注 / URL | 同上灰 | 11–12pt |

英文关键词可以**下划线**（Regression、General Guide 还带斜体）。

## 颜色

`#FF0000` 红、`#0070C0` 蓝、`#00B050` 绿、`#FFC000` 金、黑白。

| 角色 | 用法 |
|------|------|
| 红 | 红点线框圈公式、红圆角框 / 红内描边点亮当前步、红字警告。一页 1–2 处 |
| 蓝 | 公式里的 w、蓝字做法、浅蓝 `#BDD7EE` 圆角框当 f |
| 步骤块 | 淡紫 `#B4C7E7` / 浅黄 `#FFE699` / 浅珊瑚 `#F8CBAD`，带轻渐变也行 |
| 灰 | 加号、块箭头 `#A6A6A6` |
| 黄 `#FFD400` | 默认封面只给右下署名；变体 B 才点课题词；仪式页的开课时间 |

## 禁止

- 把机制的资料行 / Loss 行装进表格（提问模板表除外）
- 图标卡片网格、标题下彩条、把 2024/2021 封面品牌混进 2025
- 自制 2D 坐标轴当算法机制的主角（点 + 轴代替盒子 / 箭头 / 一笔数）。图只当 **observation / 证据**：ChatGPT 截图、SGD 路径热图、真界面。反例：BBO L08 p8 用自制坐标讲 DE 变异
- 无标注折线、手绘海岸冒充函数
- `w`/`h` 为负（斜线用 `flipH`/`flipV`，宽高为正）
- 机制页每个角色都是无脸灰盒；一页贴纸游行
- 把 Office 图表当机制讲解。图表可以有，但小、素、当证据

## 复制递增

第一张已是完整图。几何不动。三种合法动作：

1. **加一个看得见的零件**（一行资料、一项公式、一个红框、一条点线旁白）
2. **换同一条骨架的两端**（`x→f→y` 的 f 不动，只换任务的 x、y）。对照 BasicML p3 生成式下一词 vs p5 回归时长
3. **步骤块不动，底下多一句注释 / +1 句**。对照 BasicML p7 vs p8

非法：复制一张空页；只改口播。

## 流行文化

是贴在图上的一张抠图（`06-TrainingTip` p8：角色站在棕色 1-D loss 波形上），从来不是主题，也不是必选项。不要做成宝可梦 / 口号清单。
