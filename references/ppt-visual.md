# 视觉规范

对照 2025 原件（`05-BasicML` 84 页、`06-TrainingTip` 83 页、`00-LLM-intro`、`03-LLMunderstand`）得出。他的页是**画出来的一张图**：淡彩圆角块或角色 + 箭头 + 浮动演算，不是填满的工作表，不是卡片盘，不是纯口号。

## 画布

| 年代 | 尺寸 | 内容底 | 默认标题页 |
|------|------|--------|------------|
| 2025 / 2024 默认生成 | 13.333" × 7.5"（16:9） | 白 `#FFFFFF` | 纯黑 `#000000`，见下 |
| 2021 经典（用户点名才切） | 10" × 7.5"（4:3） | 白 | 黑底 + 细橙框；不要和 2025 品牌句混用 |

页边 0.45"。无页眉 Logo、无每页课程名、无底栏。

三种年份是**不同产品**。默认生成器只走 2025。不要混进：

- 2024：满版 AI 图封面 + 橙色姓名条
- 2021：4:3 Calibri 英文 + 青绿科技图 / 模糊代码底

## 标题页（2025 品牌）

封面字号 **72–96 pt 微軟正黑體**。内容页标题才是 28–36 pt。黄是 `#FFFF00`（不是 `#FFD400`）。不要强求第三行包装句，也不要强求 byline。

| 配方 | 对照 | 画什么 |
|------|------|--------|
| **(i) 默认** | `00-LLM-intro` p1、`03-LLMunderstand` p1 | 平黑。2–3 行大**白**字。03 是 96 pt 两行，可省略「的概念」。有 byline 时黄、右下。只凭这一行就该能画出 00 p1。 |
| **(ii) B** | `05-BasicML` p2 | 居中 72 pt，青绿几何底。黄只涂课题词，包装句白。**无 byline**。 |
| **(iii) C** | `06-TrainingTip` p1 | 橙→藏青渐变，右对齐约 88 pt 全白，`+` `o` `.`。byline **白、左下**。仅用户要广告封面。 |
| **(iv)** | `02-Agent` | 中英夹心。用户点名双语课时用。 |

等钟黑页可以出现在品牌封面之前（`05-BasicML` p1）：白字「请各位同学稍待片刻」，黄字开课时间。不是后勤二维码。

可选收尾：黑底 + 二维码 + Colab URL + 左侧和底边一条细橙 L 框。这是 closer，不是默认封面，也不是空白末页。

## 机制页的构图语言

2025 机制页有两条金线，贴纸不是必选项。

### 更常见：淡彩圆角块（`05-BasicML` p42）

三列胖圆角块当表头（浅蓝 / 浅黄 / 浅桃），中间灰 `+`、灰块箭头，**块下直接写算出来的数**（`L=240`、`y=1.67x₁+4.85`、`w₁*=1.67 / b*=4.85`）。w 蓝 b 红。零贴纸。留白很多。一页一个念头。

议程同构：竖叠 2–5 个彩胶囊，红内描边点亮当前步（`03-LLMunderstand` p5）。也是零贴纸。

### 有时：贴纸资料流（`05-BasicML` p5 / p11 / p14）

只在需要具象样本走 `x → f → y` 时用。角色类型 ≤3；同一资料图标可重复 3 次，**不同例子要重着色**（橙 / 绿 / 蓝），不要「生成时直接同色」。

1. **角色可选用真贴图，但不是每页都要。** `05-BasicML` 84 页里 43 页零图。物体图标：PPT 文件**没有脸**；机器人是胸口写 AI 的显示器，不是微笑手电筒 / 微笑旗。禁止给 file / box / flashlight / flag 画笑脸。禁止一页贴纸游行。BBO L01 s08 过密。公开仓若只有 `ruler.png`，**先补目录再画页**，不要用 emoji 凑角色。
2. **数字浮动，不进资料表。** 演算写成数学式：贴在箭头旁（p11：`(99−100)² = 1` 进点线演算列），或写在淡彩块正下方（p42）。E/F/K **禁止 `a:tbl`**。
3. **箭头（最容易露馅）。** 资料流默认是 `straightConnector` / `line`，**2.5–3.5 pt**，黑，`tailEnd=triangle`。旁白 / 演算映射用预设 **`sysDot`**（不要 `dash`）。`05-BasicML`：straightConnector1 ×386、line ×169、rightArrow 只有 ×12。胖 `rightArrow` / `mathPlus` **只**许灰色、只许当 G 步块之间的连接。QA：机制 deck 上 `prst="rightArrow"` ≈ 0，G 页除外。BBO L01 用 36 个 chevron 当资料流，读起来像咨询公司流程图。
4. **公式逐项上色。** `y = w₁x₁ + b`：w 蓝 `#0070C0` 或强调蓝 `#0000FF`、b 红 `#FF0000`、其余黑。第一个模型式子用**红点线框**圈住，旁边红字注释（`出自人类对于任务的理解`）、蓝字标签（`模型 (Model)`）。公式用 Cambria Math 斜体。
5. **从图标虚线往下拆特征（`05-BasicML` p16）。** 顶上一行贴纸流（文件 → 机器人 → 输出）。从文件图标垂直**虚线向下**，旁注「函数的输入只能是数字」，下列 `x₁…x₄`。右侧才是红点线框公式和更复杂的候选式。这是公式页的显式版式，不要改成无来源的子弹列表。
6. **文字有颜色语义。** 蓝字 = 该做什么 / 指模型。红字 = 关键 / 警告。黑字 = 陈述。底栏若有，是一句主张，不是复盘，更不是「本页/下一步」（见 [humanize-classroom.md](humanize-classroom.md)）。图上已有点线旁白就不要再贴 canvas caption。

### 灰盒子：禁的是替 x/f/y，不是神经元

`05-BasicML` p62 整页灰方块 + 加号画神经网络，192 个形状、零贴纸。无脸灰盒**非法**的情况：在 E 页上代替 x / f / y。**合法**：神经元、层底盘、矩阵格子。不要把机器人贴进 backprop。

回想抽象 IO 管线时，输入 / 输出 / 标准答案用彩色圆角块即可（`05-BasicML` p9）。

### 表格

`05-BasicML` 和 `03-LLMunderstand` 的 `a:tbl` 是 **0**。`06-TrainingTip` 有表的页是 22 张。只许两种例外：

- **(B2)** 2×3 方法目录：深蓝表头，红框圈一列，坐在三步块上面。对照 `06-TrainingTip` p3。格子是 `……`，不要填数字。
- **格子当图：** CNN kernel / 像素阵。看起来像表，语义是图像。

E/F/K 继续零表。课程规划表只出现在政策课（原型 B）。

## 密度（两档，不是 10–25）

`05-BasicML` 中位 18.5 个形状，p90=55，max=192。13/84 页 ≤5 个形状。CJK 中位约 47 字/页（TrainingTip ~87，LLMunderstand ~70）。「约 40 字」只防空标题页。

| 档 | 形状数 | 谁 |
|----|--------|-----|
| 稀疏拍 | 2–8（有的 ≤5） | 仪式、议程胶囊、部分钩子、三盒金页也可以看起来很疏 |
| 机制 / Loss / 公式 | 通常 **25–60**（p10=55，p16=40，p18=58） | 浮动演算、公式拆特征、盒下数字。XML 上零件多，看起来仍可留白 |
| 架构 / 网络 | **60–200**，可以零图 | p62 灰方块神经网络。合法 |

20 分钟 2025 机制课是 **50–85 页** 疏密混排，不是 24 张中等吉祥物页。

问句钩：问句 + 半条资料流 / 点线缺口 / 教室漫画。禁止只有标题，禁止风景图。

底栏整句**可以但不是必写**。已有点线旁白就不要再加 canvas caption。

公开仓不发行原件媒体。

## 字体与字号

原件 run：微軟正黑體 + 新細明體 + Cambria Math（+ Calibri）。theme 写 Aptos 没关系。用户写简体就出简体，字体可改微软雅黑。**每个 run 设 `a:ea`。** 强调蓝可用 `#0000FF`。

| 用途 | 字体 | 字号 |
|------|------|------|
| 封面大字 | 微軟正黑體（简体可用微软雅黑） | **72–96pt** |
| 内容标题 | 同上 | 28–36pt |
| 正文 / 盒内 | 同上 | 16–22pt |
| 公式与变量 | Cambria Math 斜体 | 20–40pt，宁大 |
| 浮动数字演算 | Cambria Math | 16–24pt |
| 底部注释 | 微軟正黑體 | 16–20pt |
| 脚注 / URL | 同上灰 | 11–12pt |

英文关键词可以**下划线**（Regression、General Guide 还带斜体）。

## 颜色

`#FF0000` 红、`#0070C0` 蓝、`#00B050` 绿、`#FFC000` 金、黑白。

| 角色 | 用法 |
|------|------|
| 红 | 红点线框圈公式、红圆角框 / 红内描边点亮当前步、红字警告。一页 1–2 处 |
| 蓝 | 公式里的 w（`#0070C0` 或强调 `#0000FF`）、蓝字做法、浅蓝 `#BDD7EE` 圆角框当 f |
| 步骤块 | 淡紫 `#B4C7E7` / 浅黄 `#FFE699` / 浅珊瑚 `#F8CBAD`，带轻渐变也行 |
| 灰 | 加号、块箭头 `#A6A6A6` |
| 黄 `#FFFF00` | 默认封面的右下署名；变体 B 的课题词；仪式页的开课时间。不要用 `#FFD400` |

## 禁止

- 把机制的资料行 / Loss 行装进表格（B2 方法目录和格子图除外）
- 资料流用胖 `rightArrow` chevron（咨询公司流程图）。默认是 2.5–3.5 pt 直线 + triangle 尾
- 图标卡片网格、标题下彩条、把 2024/2021 封面品牌混进 2025
- 自制 2D 坐标轴当算法机制的主角。图只当 **observation / 证据**。反例：BBO L08 p8
- 无标注折线、手绘海岸冒充函数
- `w`/`h` 为负（斜线用 `flipH`/`flipV`，宽高为正）
- 在 E 页用无脸灰盒代替 x/f/y；一页贴纸游行；给 file/flag/flashlight 画笑脸
- 把 Office 图表当机制讲解。图表可以有，但小、素、当证据
- 每页都倒一条底栏 caption；`本页算完` / `下一步` 导播字幕；否定式口号。标签与别的形状相交

## 复制递增

第一张已是完整图。剩下的几何冻结。五种合法动作：

1. **加一个看得见的零件**（一行资料、一项公式、一个红框、一条点线旁白）
2. **换同一条骨架的两端**（`x→f→y` 的 f 不动，只换任务的 x、y）。对照 BasicML p3 vs p5
3. **步骤块不动，底下多一句注释 / +1 句**。对照 BasicML p7 vs p8
4. **同一坐标轴上更新路径**（图已是证据时，轴不动）
5. **公式能独立站住后撤掉图**。对照 GD p27–29

非法：复制一张空页；只改口播。

## 资料流怎么画（python-pptx）

```python
from pptx.enum.shapes import MSO_CONNECTOR
from pptx.util import Pt, Emu
from pptx.oxml.ns import qn
from lxml import etree

c = slide.shapes.add_connector(MSO_CONNECTOR.STRAIGHT, x1, y1, x2, y2)
c.line.color.rgb = RGBColor(0, 0, 0)
c.line.width = Pt(3)  # 2.5–3.5
# tailEnd = triangle
ln = c.line._ln
tail = etree.SubElement(ln, qn("a:tailEnd"))
tail.set("type", "triangle")
# 旁白：ln 里加 a:prstDash val="sysDot"
```

`MSO_SHAPE.RIGHT_ARROW` / `mathPlus` 只许灰色，只出现在 G 的步块之间。
