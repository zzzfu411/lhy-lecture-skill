# 视觉规范

对照原件渲染页（05-BasicML p05/p08/p11/p16、overfit-v6 p04）得出。他的页是**画出来的一张图**：角色 + 箭头 + 浮动演算，不是表格、不是卡片、不是纯口号。

## 画布

| 年代 | 尺寸 | 内容底 | 标题页 |
|------|------|--------|--------|
| 2025 / 2024 默认 | 13.333" × 7.5"（16:9） | 白 `#FFFFFF` | 纯黑 `#000000` |

## 机制页的构图语言（味道就在这五条）

1. **角色化，用真贴图。** 每个抽象对象配一个看得见的形象，反复出现：
   - 模型 / 函数 = `assets/robot-f.png` 或大浅蓝圆角框，旁边斜体 *f*
   - 一笔资料 = `assets/ppt-file.png`（堆三份 + 省略号表示数据集）
   - 人 = `assets/person.png`；对错 = check/cross；找 = magnifier；全表见 [assets.md](assets.md)
   - 优先级：素材库贴图 > emoji（他本人也用 😊）> 组合形状。禁止无脸灰盒子当全部角色
2. **数字浮动，不进表格。** 演算写成数学式贴在箭头旁：`(99−100)² = 1`、`(58−101)² 巨大`。要对比多笔资料，就纵向排三行「文件图标 → f → 预测值 ⋯ 点线 ⋯ 实际值」，中间点线框圈住演算区。**机制页禁止 addTable**；表格只许出现在课程规划 / 行政页
3. **两种箭头。** 实线粗黑箭头 = 资料流（x → f → y）。**点线箭头 = 旁白**：指出「如何找出 f？」「越小越好 → Loss」。垂直点线箭头从下方指上来提问，是他的招牌
4. **公式逐项上色。** `y = w₁x₁ + b`：w 蓝 `#0070C0`、b 红 `#FF0000`、其余黑。第一个模型式子用**红点线框**圈住，旁边红字注释（`出自人类对于任务的理解`）、蓝字标签（`模型 (Model)`）。公式用 Cambria Math 斜体，变量单字母
5. **文字有颜色语义。** 蓝字 = 该做什么 / 指模型（`make your model complex`）。红字 = 关键概念 / 警告 / trade-off。黑字 = 陈述。判断树可以斜箭头自由分叉（loss 大→左、小→右），关键节点套红圆角框

## 密度（修正：疏 ≠ 元素少）

他的机制页元素很多（p11 一页约 20 个形状），干净是因为**白底、无装饰、沿箭头轴对齐**。

| 页类 | 页上应有 |
|------|----------|
| 机制页 | 一条完整的资料流（角色 + 箭头）+ 至少一笔浮动演算 + 一句注释。约 10–25 个元素 |
| 揭示页 | 同一张图多一个零件（一行资料、一项公式、一个红框） |
| 问句钩 | 问句 + 半张图或点线箭头指着缺口。禁止只有标题 |
| 步骤页 | 2–5 个低饱和圆角块 + 灰色加号/块箭头 + 红框点亮其一 + 底部一句人话 |

底部允许一整句黑字注释（他常写完整句子在页底）。

## 字体与字号

| 用途 | 字体 | 字号 |
|------|------|------|
| 标题 | 微软雅黑 / 微軟正黑體 | 28–36pt |
| 正文 / 盒内 | 同上 | 16–22pt |
| 公式与变量 | Cambria Math 斜体 | 20–40pt，宁大 |
| 浮动数字演算 | Cambria Math | 16–24pt |
| 底部注释 | 微软雅黑 | 16–20pt |
| 脚注 / URL | 同上灰 | 11–12pt |

英文关键词可以**下划线**（Regression、General Guide 还带斜体）。

## 颜色

`#FF0000` 红、`#0070C0` 蓝、`#00B050` 绿、`#FFC000` 金、黑白。

| 角色 | 用法 |
|------|------|
| 红 | 红点线框圈公式、红圆角框圈重点节点、红字警告。一页 1–2 处 |
| 蓝 | 公式里的 w、蓝字做法、浅蓝 `#BDD7EE` 圆角框当 f |
| 步骤块 | 淡紫 `#B4C7E7` / 浅黄 `#FFE699` / 浅珊瑚 `#F8CBAD`，带轻渐变也行 |
| 灰 | 加号、块箭头 `#A6A6A6` |
| 黄 `#FFD400` | 封面课题与署名 |

## 禁止

- **机制页表格**（最容易露馅的一条）
- 图标卡片网格、标题下彩条、渐变品牌卡
- 无标注折线、手绘海岸冒充函数
- `w`/`h` 为负（斜线用 `flipH`/`flipV`，宽高为正）
- 所有角色都是无脸灰盒子
- 把 Office 图表当主角。图表可以有，但小、素、配浮动标注；主角永远是那条资料流

## 复制递增

第一张已是完整资料流。后续页只多：一行资料、一项公式、一个红框、一条点线旁白。几何不动。
