# 页上的字怎么写

页上是**口号 + 路标 + 数字**，不是讲稿，也不是只有口号。讲稿进 notes。

## 标题

1. **问句**：`______ 怎么______呢？` `为什么直线永远矮一截？`
2. **口语断言**：一句人话判断。
3. **品牌句**：`一堂课搞懂 / 看懂 + 课题`。

少用：`概述` `简介` `背景` `总结` `Key Takeaways`。同一标题连用时不要为了不重复而改标题。

## 机制页最少三件套

能上页的通常要**同时**有：

1. 一个主张（标题或一句因果：`这就是为什么……`）
2. 一张完整图或表（零件有名字）
3. 至少一个数字、不等式或残差（并写「示意」如果是编的）

只有 1、没有 2 和 3，就是空页。不要交。

不要上页的：完整定义段、三层从句、「首先其次最后」、把 notes 整段贴上去。

## 图例（隐喻在干活的证据）

至少有一页写对照，之后可以只留一行小字：

`直尺 = y = b + wx`　`弯资料 = 真实关系`　`对不齐 = 训练 Loss 下不去`

没有这行，听众会把比喻当故事。

## 页上用课堂口语

| 用 | 不要换成 |
|----|----------|
| 搞懂 / 看懂 | 深入理解、全面掌握 |
| 你现场造的比喻 + 图例 | 论文术语当唯一标题 |
| 请注意 | 值得注意的是 |

中英并置一次：`学习 (Learning)`。不要把他某一年的口号做成必用词表。

## 诚实简化

- `（数字是示意）`
- `请注意：今天不推 ______`
- `假设……虽然实际上并非如此`

脚注字小，必须在。示意指数字假，不指图画可以乱。

## 幽默（必须是机制）

好：听众正在过的场面 + 一个具体的失败者 + 一个不公平的数字。  
例如：助教用直线外推「80 页还要讲 100 分钟」，其实老师已经在收作业——直线太笨，不是助教没认真。

坏：只有大问句、抽象风景、为了像他而塞二次元、空泛「AI 要取代人类哈哈」。

反话封面、拆穿、轻度恐吓可以，但下一页必须把机制画完。

## 中英混排

模型名、方法名留英文。动词和判断用中文。不要整页英文，除非用户要 2021 经典。

## 页序

```
p1  封面
p2  钩子：听众正在过的场面 + 半张表
p3  同一张表补全 / 上图
p4  同一张图出现「失败者」的那一笔（拟合、残差）
p5  课核句 + 图例
p6–  机制拆开，每页一个新数字
```

每页新增必须看得见。只改 notes 不算新页。
