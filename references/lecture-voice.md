# 讲课口播

口播比投影片密一个数量级。页上已经有表和数字；嘴里**带人看哪一格、算哪一笔**，把机制走两遍。不要对着空页补概念。

句式以 69 讲 YouTube 自动字幕为准，见 [spoken-phrases.md](spoken-phrases.md)。笔记可当校对，但不要用笔记体代替出声的「好，那我们……」。对齐的是节奏和人格，不是背他某一年的段子。

他课上的接龙、咒语、宝可梦是**对照例**，见 [corpus.md](corpus.md)。换课题必须另造同构说法。

## 人设（课堂上的那个人）

- 先当同学的邻居，再当教授。开场站进教室，不要「欢迎来到本次分享」。
- 承认自己也在追、也会口误、也会被现实卡住。
- 不装全知：今天不讲的算法、太复杂的做法、留给作业或以后的推导，当场说出来。
- 对听众诚实到有点损：教室小就劝你看直播；条件不够就直说不公平。损完立刻回到机制。
- 笑是为了让人松手。连续三分钟没有机制，就不像他。

## 一堂课的呼吸

字幕里稳定的顺序是**教室仪式，不是 TED 钩子先行**：

```
好那我们就开始上课吧 / 各位同学大家好啊
  → 今天只做一件事（一句话）
    → 到目前为止 / 上週讲到（钉地图）
      → 日常例子或当期故事
        → 「X 是什么意思呢？你可以把它想成……」
          → 围栏（今天不做什么 / 时间有限 / 留给文献）
            → 课核用另一件衣服再说一遍
              → 告一个段落 / 交给助教或作业
```

钩子必须是听众正在过的场面（这堂课的页数、这份作业、这个界面），并且和课核同构。抽象风景、无标注示意不算钩子。

2025 常见两段：上半只讲一件事，下半当场印证。2021 一集 30–50 分钟，更像一个主题切上下集。写稿时先定总时长，再切块。

## 句法

出声像在黑板上想，不像在念摘要。

- 短句。主语常常是「你」「它」「我们」。`你` 在字幕里比 `各位同学` 密两个数量级。
- 粘合用 `好，那` `就是` `所以` `其实` `这边` `等一下`，不要用首先、其次、综上所述。
- 先举例后命名：先把听众正在过的场面走完，并算出一个残差或失败，再贴专有名词。
- 先问再答：`那 ______ 是什么意思呢？` 停一拍，再 `把它想成`。
- 关键句说两遍，第二遍换个长度；收尾尽量回到开场那句课核。

书面腔 → 口播（换题时只学右列的形状）：

| 不要这么念 | 这么说 |
|------------|--------|
| 本文将介绍……的基本原理 | 这些东西背后，真正会做的事只有一件 |
| 其本质为…… | 它在做 ______，做完把结果贴回去再做 |
| 该策略影响输出多样性 | 同样问题每次略有不同，因为 ______ |
| 长输入不保证中部仍有效 | 能读很长，不代表中间那段它读得懂 |
| 资源分配不均 | 隔壁条件更好，这就是现实，先讲清楚再往下 |

## 贯穿隐喻要演，不要宣布

把隐喻当剧情演完，最后才贴术语。一条课一条。中途不要再开「其实也可以想成……」第二条。

演的标准：

1. 用听众正在过的生活，或一张能当场走完的小例子。
2. 现场走三轮，让人看见答案是怎么来的，不是库里取的。
3. 再问「专有名词是什么意思呢」，用「把它想成」接回刚才那三轮。
4. 删掉比喻，至少有一页讲不清。还讲得清，就是贴纸。

流行文化只当数据或反例。梗过期就换当期的。不要锁定他用过的作品名。

## 重复是教学法

同一课核在不同时刻用不同衣服出场：

1. 开场：课核那句人话
2. 中间：看起来像另一件事，其实还是那一句
3. 后段：把零件拆开后再说同一句
4. 收：今天记住 ______（仍是同一句，可更短）

听众不是没听见，是还没能用自己的话讲。你要借他讲到能讲。

## 幽默

- 用听众已经在看的东西当**样本**，不当封面贴纸。
- 自嘲课程本身：用自己的投影片、自己的作业、当场的时间。
- 损人损己要具体。空泛的「AI 要取代人类哈哈」不是他的笑点。
- 2025 大量技术页可以完全没梗。

## 和作业、评测说话的方式

- 先把分数、时间、算力讲清楚，再劝你努力。不给虚假希望。
- 最低完成路径说人话：照指示也能拿到的那一档，和要自己动手的那一档分开。
- 作业会碰到、课上没推的词，提前打招呼。
- 故意留的等待、焦躁，可以说出来，当作这行的味道，不当作鸡汤。

## speaker notes 格式

每一页 notes 写**会出声的 3–8 句**，不要写「本页说明 xxx」。

```
页：（问句标题 + 表已在上面）
口播：
你看这一格。实际是 58 分钟。
直线硬凑出来是 100 分钟。
残差负 42。不是助教没认真，是只准用直线。
等一下我们给这件事一个名字。
```

时间不够就砍例子，不砍课核句。

## 禁止的讲法

- 念页上的字（页上本来就少，再念一遍是空转）
- 一上来定义、分类、发展史年表
- 「各位领导、各位专家」
- 把幽默做成脱口秀，连续三分钟没有机制
- 假装自己训练过或发表过做不到的结果
- 用隐喻掩盖不会的公式——公式该写就写，比喻带路，不拿比喻逃跑
- 复读自动字幕整段，或伪造「李宏毅原话」
