# 剔出来的两件事

只保留**换任何题目都还成立**的习惯。自检：拿过拟合、回归分析、一篇无关论文当课题，下面这些仍然够用。他课上的接龙、咒语、宝可梦是例，不是风格。对照例见 [corpus.md](corpus.md)。

上一版把「字少 / 空白 / 复制递增」写成了空页和烂折线。那是过拟合 skill，不是李宏毅。他页上比咨询公司课件疏，但**每一页都站得住**：有零件名、有数字或不等式、有一句因果。空问句是调味，不是主食。

## 一、做 PPT

像用记号笔在白板**画完一张有角色的图**，不像做品牌演示，不像填工作表，也不像只写标题。

1. **内容页白底，标题页才黑。** 没有 Logo、没有每页课名、没有标题下彩条、没有三列图标卡片。
2. **每页是一条画出来的资料流，不是表格。** 角色（机器人 / 文件图标 / emoji / 浅蓝 f 框）+ 粗黑箭头 + 浮动的数学演算（`(99−100)²=1` 贴在箭头旁）。**机制页禁止表格**；表格只许出现在课程规划页。他的 Loss 页是三行「文件图标 → f → 预测 ⋯ 实际」加一个点线演算框，没有一格表。
3. **抽象概念角色化。** 模型 = 机器人图 + 斜体 *f*；一笔资料 = 彩色文件图标；人 = 火柴人或 emoji（他自己在判断树里放 😊）。没有真图就用大号 emoji 或组合形状，禁止全页无脸灰盒子。
4. **两种箭头两种话。** 实线粗黑 = 资料流。点线 = 旁白提问（`如何根据资料找出 f？` 从下方点线指上来）。
5. **公式逐项上色。** `y = w₁x₁ + b`：w 蓝、b 红。第一个模型式子套红点线框，旁边红字讲来历、蓝字贴标签。文字也有色义：蓝字 = 做法，红字 = 关键 / 警告。
6. **动画等于复制下一页。** 第一张已是完整资料流；每页只多一行资料、一项公式或一个红框。暂停任何一页都能说出主张。
7. **密度修正：疏 ≠ 元素少。** 他的机制页一页约 10–25 个元素，干净靠白底和沿箭头对齐。只有标题的机制页、无演算的机制页都算失败。底部可以写一整句黑字注释。
8. **图要能算、能停、能指。** 每个零件有名字；示意只表示数字是假的，图必须对齐可读。OOXML 宽高必须为正，斜线用翻转。
9. **隐喻要上图例。** 页上有一行「日常物 → 技术对象」对照。流行文化只当数据或反例。
10. **脚注式诚实 + 封面像广告。** 小字「虽然实际上并非如此」。封面 `一堂课搞懂 + 课题`，右下黄名。英文关键词可下划线。

尺寸默认 16:9（13.333"×7.5"）。用户点名 2021 才改 4:3、更密。细则：[ppt-visual.md](ppt-visual.md)、[ppt-rhetoric.md](ppt-rhetoric.md)、[slide-archetypes.md](slide-archetypes.md)。

## 二、说话

像在黑板上**边指表边讲**，不像念摘要，也不像对着空页讲故事。

1. **先站进教室，再讲今天一件事。** `好，那我们就开始上课吧`。不要「欢迎来到本次分享」。
2. **对「你」说。** 钩子要用听众**正在过的场面**（这堂课的页数、这份作业、这个平台），不要用抽象海岸。
3. **短句，口语粘合：** `好，那` `就是` `所以` `其实` `这边` `等一下`。
4. **先演一笔能算的，再给名字。** 先让人看见一张表、一个残差、一次失败，再问「X 是什么意思呢」，再「把它想成」。
5. **先声明今天不讲什么**，再往下走。
6. **一条能演算的比喻**，而且页上有图例。演完再贴术语。
7. **同一句课核换三套衣服。** 收尾常是 `告一个段落`。
8. **笑点必须是机制。** 具体的失败者 + 一个不公平的数字。空问句不叫生动。连续三分钟没有机制就不像他。
9. **不念投影片。** 页上已经有表，口播是带人看哪一格、算哪一笔。

句式：[spoken-phrases.md](spoken-phrases.md)。节奏：[lecture-voice.md](lecture-voice.md)。

## 刻意不要学的

- 把他某一年的课题口号当成通用词表。
- 每页二次元。
- 伪造「李宏毅原话」。
- 组会论文风或咨询公司卡片风。
- **空页当风格、烂折线当示意、只有标题当问句钩。** 这是第一版 skill 的病。
- **满页表格当密度、灰盒子当角色。** 这是第二版 skill 的病。他的密度长在资料流和浮动演算上，不长在表格里。
