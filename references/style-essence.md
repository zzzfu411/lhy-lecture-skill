# 剔出来的两件事

只保留**换任何题目都还成立**的习惯。自检：拿过拟合、回归分析、一篇无关论文当课题，下面这些仍然够用。他课上的接龙、咒语、宝可梦是例，不是风格。对照例见 [corpus.md](corpus.md)。

上一版把「字少 / 空白 / 复制递增」写成了空页和烂折线。那是过拟合 skill，不是李宏毅。他页上比咨询公司课件疏，但**每一页都站得住**：有零件名、有数字或不等式、有一句因果。空问句是调味，不是主食。

---

## 一、做 PPT

像用记号笔在白板**画完一张有零件的图**，不像做品牌演示，不像填工作表，也不像只写标题。贴纸可有可无。

1. **内容页白底，标题页才黑。** 没有 Logo、没有每页课名、没有标题下彩条、没有三列图标卡片。默认封面是黑底**全白**大字 + 右下黄名（`00-LLM-intro` p1），不是黄课题，也不是 2024 满版 AI 图。
2. **每页是画出来的一张图，不是填满的工作表。** 2025 更常见：2–5 个淡彩圆角块 + 灰加号 / 块箭头 + 盒下或箭头旁的一笔数（`05-BasicML` p42，零贴纸）。有时才是贴纸资料流（p11）。**不要把机制的资料行装进表格**；空的提问模板表可以（`06-TrainingTip` p3）；课程规划表可以。
3. **贴纸可选，不是每页必嵌。** 模型可以是浅蓝块 + 斜体 *f*，也可以是机器人图。禁止机制页**全部**角色都是无脸灰盒，也禁止一页贴纸游行。回忆 IO 管线用彩色圆角块即可。
4. **两种箭头两种话。** 实线粗黑 = 资料流。点线 = 旁白提问。步骤页用灰加号 / 块箭头，红内描边点亮当前步。
5. **公式逐项上色。** `y = w₁x₁ + b`：w 蓝、b 红。第一个模型式子套红点线框，旁边红字讲来历、蓝字贴标签。公式页从图标虚线向下拆 `x₁…x₄`。
6. **动画等于复制下一页。** 第一张已是完整图。合法动作只有三种：加一个看得见的零件；同一条 `x→f→y` 只换两端；步骤块不动、底下多一句。暂停任何一页都能说出主张。
7. **密度：疏 ≠ 空，也 ≠ 塞满。** 「约 40 字」是防空页的地板，不是目标。三盒 + 一笔数就够。只有标题的页失败。宁可留白。
8. **图要能算、能停、能指。** 每个零件有名字；示意只表示数字是假的，图必须对齐可读。自制坐标轴不当机制讲解。OOXML 宽高必须为正。
9. **隐喻要上图例。** 页上有一行「日常物 → 技术对象」对照。流行文化是贴在图上的抠图，不是主题，不是必选项。
10. **脚注式诚实。** 小字「虽然实际上并非如此」。封面走 2025 黑底品牌句，广告渐变封面仅用户点名。英文关键词可下划线。

尺寸默认 16:9（13.333"×7.5"）。用户点名 2021 才改 4:3、更密。细则：[ppt-visual.md](ppt-visual.md)、[ppt-rhetoric.md](ppt-rhetoric.md)、[slide-archetypes.md](slide-archetypes.md)。

## 二、说话

像在黑板上**边指表边讲**，不像念摘要，也不像对着空页讲故事。

1. **先站进教室，再讲今天一件事。** `好，那我们就开始上课吧`。不要「欢迎来到本次分享」。
2. **对「你」说。** 钩子要用听众**正在过的场面**（这堂课的页数、这份作业、这个平台；半条资料流 / 点线缺口 / 教室漫画），不要用抽象海岸。
3. **短句，口语粘合：** `好，那` `就是` `所以` `其实` `这边` `等一下`。
4. **先演一笔能算的，再给名字。** 先让人看见一个残差、一次失败，再问「X 是什么意思呢」，再「把它想成」。
5. **先声明今天不讲什么**，再往下走。
6. **一条能演算的比喻**，而且页上有图例。演完再贴术语。
7. **同一句课核换三套衣服。** 收尾常是 `告一个段落`。
8. **笑点必须是机制。** 具体的失败者 + 一个不公平的数字。空问句不叫生动。连续三分钟没有机制就不像他。
9. **不念投影片。** 页上已经有图和数，口播是带人看哪一盒、算哪一笔。

句式：[spoken-phrases.md](spoken-phrases.md)。节奏：[lecture-voice.md](lecture-voice.md)。

## 刻意不要学的

- 把他某一年的课题口号当成通用词表。
- 每页二次元。
- 伪造「李宏毅原话」。
- 组会论文风或咨询公司卡片风。
- **空页当风格、烂折线当示意、只有标题当问句钩。** 这是第一版 skill 的病。
- **满页表格当密度、灰盒子当角色、每页必贴机器人。** 第二版 skill 的病。他的密度长在一笔算出来的数上；许多金页零贴纸。
- **自制坐标轴当算法机制、一页贴纸游行。** 图只当证据；角色类型 ≤3。
