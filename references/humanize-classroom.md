# 课堂口语禁止清单

杠杆来自 [harshaneel/humanize](https://github.com/harshaneel/humanize) 的 9 条，**改写成李宏毅课堂中文**。不要整本搬英文作文 humanize：不要第一人称回忆录，不要给 12 个字的标题设 20-word 下限。寄存器是教室里出声的话，不是 essay。

页上和 notes 都过这张单。细则的反例见 [anti-patterns.md](anti-patterns.md)。

## 1. 舞台指示 chrome（删，永不生成）

页上禁止出现导播字幕。这些词一出现就重做：

- `本页算完` / `本页在干什么` / `本页做完`
- `下一步` / `接下来会` / `接下来算` / `接下来动 σ 和 C`
- 任何脚注、底栏、盒下小字，职务是「告诉读者这页在干什么、下页算什么」
- 没用到的参数盒底下写状态（σ / C 盒下写「下一步」）

没算的参数：整盒拿掉，或静静放着、**零说明**。红描边点亮正在算的那一盒就够。

**也不要把字塞进两层块之间的 8 pt 缝。** 「本页算完」楔进蓝色演算块，是 chrome 不该存在的症状，不是排版问题。先删字，不要缩字号。

## 2. 复述黄条（删）

底栏若存在，只能是**一句出声的主张**，不是复盘。他很少复述自己刚讲完的页。

禁止：

- `笑点不是…` / `笑点是…` / `关键不是…而是…`
- 任何把本页算术再讲一遍的句子
- 任何导览句：`这页算完 X，下页算 Y`

坏（CMA 均值更新页的黄条）：`笑点不是 1 加错。圆心去三个精英的中心，不是旗子 A。σ 和 C 还没动。`

好：标题本身就是主张。要补一句就补人话，例如 `三个留下来的人平均一下，当新圆心。`

## 3. 不说「不是 X，是 Y」（杠杆：直接说它是什么）

硬规则：禁止否定式口号。

- `不是 X，是 Y`
- `不是关于 X，是关于 Y`
- `笑点不是…`
- `不去最好的 A`

对比用**同一页上的两个数**（`μ'=(1,0.67)` 旁边写 `A=(2,1)`），不要用标语。嘴里可以说「第一名再好，也不把圆心搬到他脚底下」——那是一句主张，不是「不去旗子 A」当标题动作。

## 4. 不开「关键是：」（杠杆：不宣布要讲什么）

禁止冒号开场：`关键是：` `要点：` `核心思想：` `笑点是：`

标题就是论点。不要先报幕再上场。

## 5. 不复述收尾（humanize 杠杆 4）

人不会讲完再总结自己刚说的话。页算完就翻页。notes 里不要写「本页说明 / 本页我们刚刚算了」。

## 6. 没有书面填充

禁止：`值得注意的是` `需要强调的是` `总结一下` `接下来我们看看` `这里有三个要点` `首先、其次、综上所述`

课堂粘合用：`等一下` `你看` `所以` `就是这个` `好，那`。短，直接。

## 7. 一个对象一个名字

同一指称全程一个名词。不要这一页「精英」、下一页「旗子」、再一页「最好的人 / 第一名」都指 point A。先定名，画出来，再复用。

## 8. 底栏节奏（burstiness）

底栏若有字：四字短打和一句稍长的人话可以并排，**不要三行一样长的口号**。标题 12 个字就 12 个字，不要为了「像人写的」拉长。

## 9. 不要搬英文 essay 的尺子

课堂中文不是 memoir。不要第一人称抒情，不要 word-count 地板，不要把「具体」做成形容词堆。具体 = 页上有一个算出来的数。

## 比喻一拍测试（李宏毅的杠）

他能落地的比喻一拍就懂：`这堂课多长` ← PPT 文件；`直尺只能画直线`。

过关：

1. **听完一句**，学生能不靠比喻把机制讲回去。
2. 那个物件**已经在页上**，或人人都认识（一堂课、一份文件、一把尺）。不要发明 `旗子` / `照片对字母` / `螺丝是步长` / `基因组上写了两槽`，除非上一页已经画出来并定名。
3. 比喻还要第二句才能解释自己 → **删比喻，留数字**。
4. 对比用两个数，不用标语。

CMA 均值更新，过关的说法（例子，不是唯一许可句）：

> 三个留下来的人平均一下，当新圆心。第一名再好，也不把圆心搬到他脚底下。

这句听得懂。`旗子 A0` 听不懂——页上没画旗。
