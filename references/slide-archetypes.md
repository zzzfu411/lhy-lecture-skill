# 幻灯片原型

先对节拍选原型。一页一个主原型。复制递增只能拆**已经完整**的图。几何不动，三种合法动作见文末。

## A. 黑底标题（2025 默认品牌）

满版纯黑。2–4 行超大**白字**：`一堂课搞懂 / 看懂` + 课题 + `的原理 / 的概念`。课题也是白的。黄只给右下 byline。对照 `00-LLM-intro` p1、`03-LLMunderstand` p1。

- **变体 B：** 只把课题词涂黄，包装句仍白。对照 `05-BasicML` p2。课题是一对要点亮的词时用。
- **变体 C（稀有）：** 渐变 / 图形广告封面。对照 `06-TrainingTip` p1。仅用户要「广告封面 / designed cover」。

不要把变体 B 当成默认（BBO L08 封面把课题涂黄，是 B，不是错，但生成器先走全白字）。不要把变体 C 当默认。

## A0. 稍待片刻（可选第 0 页）

黑底课堂仪式，不是后勤二维码（那是 C）。白字「请各位同学稍待片刻 / 我们 HH:MM 开始上课」，**时间用黄**。对照 `05-BasicML` p1。

## B. 课程地图

**页上：** 表（讲次 / 日期 / 主题），深蓝表头，红框捆成一句人话。课程规划表合法。

## C. 后勤黑页

黑底、大二维码、完整 URL。可选细橙 L 框（左 + 底）当 closer：QR + Colab URL，不是空白末页，也不是默认封面。

## D. 问句钩

**页上：** 大口语问句 + **一种**伴奏：半条资料流、指着缺口的点线箭头、或听众本人的教室场景漫画（`05-BasicML` p6：发呆学生想「什么时候下课」）。禁止只有标题。禁止风景 / 图库山水。禁止「半张表」当唯一默认。

## E. 角色资料流（有些课才用）

文件图标（输入 x）→ 粗黑箭头 → 机器人或浅蓝圆角框（*f*）→ 粗黑箭头 → 输出。下方点线箭头提问。同一文件图标可重复 3 次并**按行重着色**。贴纸只出现在部分资料流页（BasicML p5/p11/p14），不是每张机制页的必选项。

## F. 浮动演算（代替机制资料表）

纵向三行：`文件图标(第1笔) → f → 预测 99 ⋯点线⋯ (99−100)²=1 ⋯点线⋯ 实际 100`，第二三行换数字，中间点线大框圈住演算列，底部 `越小越好 ⋯→ Loss`。对照 `05-BasicML` p11。**不要把这些数字放进表格。** 数字标「示意」。

## G. 步骤块 / 机制带数字（2025 更常见的金页）

2–5 个低饱和圆角块。对照 `05-BasicML` p42：三列胖块当表头，灰 `+` 再块箭头，**块下写算出来的数**，w 蓝 b 红，零贴纸，留白多。块里是口语并且带一个数字，不是空口号。

议程：竖叠彩胶囊，红内描边点亮当前步（`03-LLMunderstand` p5）。也是零贴纸。

## H. 同一图上的质疑

两张几乎一样的图。`similar?` / `different?`。两边都要有数。不要为此改画一张自制坐标轴。

## I. 真截图

1–3 张带细框的真图，来源 URL。图是 observation。

## J. 全幅图当证据

图本身是 observation（产品 UI、SGD 路径热图、论文图）。删掉就少一块证据才留。禁止把自制 2D 轴 + 点当成算法机制讲解（反例：BBO L08 p8）。

## K. 公式逐项上色 + 从图标虚线拆特征

对照 `05-BasicML` p16：

1. 顶上一行：文件贴纸 → *f* / 机器人 → 输出。
2. 从文件图标**垂直虚线向下**，旁注「函数的输入只能是数字」，下列特征 `x₁…x₄`（页数、总字数……）。
3. 右侧第一式 `y = w₁x₁ + b` 套红点线框；w 蓝、b 红；红字注 `出自人类对于任务的理解`，蓝字标 `模型 (Model)`。
4. 往下逐行加项，底部点线 + `有无尽的可能`。

不要把左侧改成无来源的子弹。

## L. 判断树 / 对比

斜箭头自由分叉：`loss on training data` → `large / small` 各走一边，关键节点套红圆角框，蓝字写该做什么，红点线箭头标 trade-off，快乐出口放 😊。或同一张图复制两遍只改一处。

## M. 论文角落

主图仍是自己的图，角落一行 arXiv。

## N. 请注意

`请注意在这堂课中` + 一句假设。可以单独成页，但不要只有这一句；补半行「所以我们只用直线」。

## O. 数字冲击

一个超大的真数字 + 一行口语。不要仪表盘。

## P. 手写 / 现场算

三行能跟着算的式子。丑可以，乱不行。数字仍不要进机制资料表。

## Q. 图例页

日常物 → 技术对象，三到五行。机制课至少出现一次。

## T. 提问模板表（表格例外）

空的 / 省略号三列表，列表头是学生该问自己的问题。对照 `06-TrainingTip` p3：方法名 / 改了哪一个步骤 / 带来什么好处；红圆角框圈住要紧列；下面可以接步骤块。不要往格子里填数字。课程规划表走 B，不走这里。

## 一讲怎么拼

```
A0 稍待片刻（可选）
A  封面（默认全白字 + 右下黄名）
D  钩子（问 + 半条资料流 / 点线缺口 / 教室漫画）
E  或 G（资料流 或 淡彩块 + 一笔数；不要每页都贴纸）
K  公式页则虚线拆特征
F  若在算 Loss：浮动演算，不要表格
T  若在教「听方法时该问什么」：空模板表
Q  图例
L  判断树
N  请注意
G  步骤块（红内描边逐页点亮；底下可 +1 句）
P  当场算
课核回声
C  收尾 QR（可选橙 L 框），不是空白末页
```

## 复制递增（三种合法动作）

几何不动。

1. 加一个看得见的零件（行、公式项、红框、点线旁白）
2. 同一条 `x→f→y` 只换两端（换任务，f 不动）。BasicML p3 vs p5
3. 步骤块不动，底下多一句。BasicML p7 vs p8

非法：复制空页；只改口播。
