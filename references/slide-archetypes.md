# 幻灯片原型

先对节拍选原型。一页一个主原型。复制递增只能拆**已经完整**的图。剩下的几何冻结，五种合法动作见文末。

## A. 黑底标题（2025 默认品牌）

封面 **72–96 pt**。平黑，2–3 行大**白**字。黄 `#FFFF00` 只给署名（有的话）。不要强求第三行或 byline。对照 `00-LLM-intro` p1；`03-LLMunderstand` p1 是 96 pt 两行，可省略「的概念」。

- **变体 B：** 居中 72 pt，青绿几何底，黄只涂课题词，**无 byline**。对照 `05-BasicML` p2。
- **变体 C（稀有）：** 橙→藏青渐变，右对齐约 88 pt 全白，byline **白、左下**。对照 `06-TrainingTip` p1。仅用户要广告封面。
- **变体 (iv)：** `02-Agent` 中英夹心。用户点名双语课。

不要把变体 B 当成默认（BBO L08 封面把课题涂黄，是 B，不是错，但生成器先走 (i)）。不要把变体 C 当默认。

## A0. 稍待片刻（可选第 0 页）

黑底课堂仪式，不是后勤二维码（那是 C）。白字「请各位同学稍待片刻 / 我们 HH:MM 开始上课」，**时间用黄**。对照 `05-BasicML` p1。

## B. 课程地图

**页上：** 表（讲次 / 日期 / 主题），深蓝表头，红框捆成一句人话。课程规划表合法。

## C. 后勤黑页

黑底、大二维码、完整 URL。可选细橙 L 框（左 + 底）当 closer：QR + Colab URL，不是空白末页，也不是默认封面。

## D. 问句钩

**页上：** 大口语问句 + **一种**伴奏：半条资料流、指着缺口的点线箭头、或听众本人的教室场景漫画（`05-BasicML` p6：发呆学生想「什么时候下课」）。禁止只有标题。禁止风景 / 图库山水。禁止「半张表」当唯一默认。

## E. 角色资料流（有些课才用）

文件图标（输入 x）→ **2.5–3.5 pt 直线 + triangle 尾** → 机器人或浅蓝圆角框（*f*）→ 直线 → 输出。下方 **sysDot** 点线提问。不要用胖 `rightArrow`。同一文件图标可重复 3 次并**按行重着色**。贴纸只出现在部分资料流页（BasicML p5/p11/p14），43/84 页零图。物体图标不要画笑脸。

## F. 浮动演算（代替机制资料表）

纵向三行：`文件图标(第1笔) → f → 预测 99 ⋯点线⋯ (99−100)²=1 ⋯点线⋯ 实际 100`，第二三行换数字，中间点线大框圈住演算列，底部 `越小越好 ⋯→ Loss`。对照 `05-BasicML` p11。**不要把这些数字放进表格。** 数字标「示意」。

## G. 步骤块 / 机制带数字（2025 更常见的金页）

2–5 个低饱和圆角块。对照 `05-BasicML` p42：三列胖块当表头，灰 `+` / 灰 `rightArrow`（**这是 rightArrow 唯一合法出场**），**块下写算出来的数**，w 蓝 b 红，零贴纸，留白多。

机制课必须用**同一组**三步块走三页（红内描边逐页点亮）。把这三种淡彩当普通节点填色，不算 G。

议程：竖叠彩胶囊，红内描边点亮当前步（`03-LLMunderstand` p5）。也是零贴纸。

## H. 同一图上的质疑

两张几乎一样的图。`similar?` / `different?`。两边都要有数。不要为此改画一张自制坐标轴。

## I. 真截图

1–3 张带细框的真图，来源 URL。图是 observation。

## J. 全幅图当证据

图本身是 observation（产品 UI、SGD 路径热图、论文图）。删掉就少一块证据才留。禁止把自制 2D 轴 + 点当成算法机制讲解（反例：BBO L08 p8）。

## K. 公式逐项上色 + 从图标虚线拆特征

对照 `05-BasicML` p16：

1. 顶上一行：文件贴纸 → *f* / 机器人 → 输出。
2. 从文件图标**垂直虚线向下**，旁注「函数的输入只能是数字」，下列特征 `x₁…x₄`（页数、总字数……）。
3. 右侧第一式 `y = w₁x₁ + b` 套红点线框；w 蓝、b 红；红字注 `出自人类对于任务的理解`，蓝字标 `模型 (Model)`。
4. 往下逐行加项，底部点线 + `有无尽的可能`。

不要把左侧改成无来源的子弹。

## L. 判断树 / 对比

斜箭头自由分叉：`loss on training data` → `large / small` 各走一边，关键节点套红圆角框，蓝字写该做什么，红点线箭头标 trade-off，快乐出口放 😊。或同一张图复制两遍只改一处。

## M. 论文角落

主图仍是自己的图，角落一行 arXiv。

## N. 请注意

`请注意在这堂课中` + 一句假设。可以单独成页，但不要只有这一句；补半行「所以我们只用直线」。

## O. 数字冲击

一个超大的真数字 + 一行口语。不要仪表盘。

## P. 手写 / 现场算

三行能跟着算的式子。丑可以，乱不行。数字仍不要进机制资料表。

## Q. 图例页

日常物 → 技术对象，三到五行。机制课至少出现一次。

## T. 2×3 方法目录（表格例外 B2）

`05` / `03` 的 `a:tbl` 是 0。唯一像表的机制例外：2×3 方法目录，深蓝表头，红框一列，**坐在三步块上面**。对照 `06-TrainingTip` p3。格子是 `……`。CNN kernel / 像素阵走「格子当图」，不是 T。课程规划表走 B。E/F/K 零表。

## 一讲怎么拼

```
A0 稍待片刻（可选）
A  封面（默认全白字 + 右下黄名）
D  钩子（问 + 半条资料流 / 点线缺口 / 教室漫画）
E  或 G（资料流 或 淡彩块 + 一笔数；不要每页都贴纸）
K  公式页则虚线拆特征
F  若在算 Loss：浮动演算，不要表格
T  若在教「听方法时该问什么」：空模板表
Q  图例
L  判断树
N  请注意
G  同一组三步块走三页（红内描边逐页点亮；灰 + / rightArrow 只在这里）
P  当场算
课核回声
C  收尾 QR（可选橙 L 框），不是空白末页
```

## 复制递增（五种合法动作）

剩下的几何冻结。

1. 加一个看得见的零件（行、公式项、红框、点线旁白）
2. 同一条 `x→f→y` 只换两端（换任务，f 不动）。BasicML p3 vs p5
3. 步骤块不动，底下多一句。BasicML p7 vs p8
4. 同一坐标轴上更新路径（图已是证据）
5. 公式能独立站住后撤掉图。GD p27–29

非法：复制空页；只改口播。
