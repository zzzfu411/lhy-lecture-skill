# 口播句式（来自字幕，不是语录库）

2026-08 用 yt-dlp 拉了 69 讲自动字幕（约 119 万字）：2025 全年 12 讲、2024 播放列表 20 讲、2021 播放列表 35/40 讲。自动字幕有错字和重复，**抄结构，不要整段当原话背**。生成时换成当前课题的内容。

频次按「每万字」粗算，跨三年很稳：`你` ~103，`这个` ~83，`那` ~82，`我们` ~64，`就是` ~38，`所以` ~35，`其实` ~17。书面连接词（首先、其次、由此可见）几乎不出现。

## 开场仪式（几乎每讲都有）

先站到教室里，再宣布今天只做一件事。不要用「欢迎来到本次分享」。

同构：

```
好，那我们就开始上课吧。
各位同学大家好啊。
今天这堂课是要来〔一堂课搞懂 / 跟大家讲〕______。
到目前为止，我们〔已经说了 / 还没做〕______。
```

字幕里的形状（供校对，勿整段复读）：

- `好，那我们来上课了` / `好那我们就开始上课吧`
- `各位同学大家好啊，今天这堂课是一堂课搞懂……`
- `好，来上课啦。好，那这个第一堂课啊，要告诉大家的就是……`
- `感谢大家来……这门课捧场。那我们就开始上课。我是李宏毅。`

2021 更常接着上周：`好那上週呢我们讲到了……接下来我要告诉大家……`  
2024/2025 更常先圈范围：`在本节课中没有任何的模型被训练`。

## 定位：你现在站在地图哪一格

每开一个新块，先用一句把旧课钉住：

- `到目前为止呢，我们……`
- `上週讲到哪里呢`
- `从这一堂课开始，我们要讲……`
- `接下来要讲什么呢。讲完了 A 以后，我们要讲另外一个……`

## 拆词：先丢名字，再问「是什么意思呢」

「X 是什么意思呢」在语料里反复出现。不要先给教科书定义。

```
这个东西有一个专有名词，叫做 ______。
那 ______ 是什么意思呢？
你可以把它想成 ______。
```

「把它想成」是他的定义动词（语料约 80+ 次）：`你可以把它想成是一个函数` / `你就把它想成是 KK 音标` / `完全可以把它想成一个分类的问题`。

## 围栏：今天不讲什么

比「深入浅出」更像他的是**先声明不做的事**：

- `在本节课中没有任何的模型被训练`（2024/2025 反复出现）
- `因为时间有限的关系，所以我们就讲一个可以在 20 分钟内讲完的版本`
- `更详细的解决方法，我们就把它留在文献里面`
- `更细的东西农场文最喜欢讲，但……往往还是看 ______`

作业交接说人话：`等一下助教就会讲跟这有关的作业` / `作业的部分会让大家……`。不要说「课后请自行复习本章」。

对照（他原课，勿当通用词）：`农场文最喜欢讲这种神奇咒语了`。

## 课核回声（同一件事换衣服）

字幕里同一讲会把课核说很多遍。写法：开场用隐喻，中间用机制，收尾用同一句隐喻 +「只是 ___ 不一样」。

对照（2025 训练史收尾，换题不要照抄）：`一、二、三阶段都是在学文字接龙，只是训练的资料不一样而已。`

## 连接词（speaker notes 里要看得见）

用这些把短句粘起来，才会像在黑板上想：

| 用 | 作用 |
|----|------|
| 好，那…… | 换气、翻页 |
| 那……呢 | 提出下一步 |
| 就是 | 收成定义 |
| 所以 | 从例子走回课核 |
| 其实 | 纠听众可能的误会 |
| 这边 | 指投影片上的那一块 |
| 等一下 | 预告还没画的零件 |
| 对不对 / 有没有 | 2021 课堂确认；2025 少很多，不要每句都加 |

不要用：首先、其次、综上所述、值得注意的是、在座各位。

## 对「你」说话

`你` 的密度远高于 `各位同学`。稿子里主语用你、它、我们，少用「学习者」「同学们应当」。

## 收尾（常常不漂亮）

他很少「谢谢大家，我们总结三点」。更常见：

- `好，那讲到这边呢，我们就告一个段落`
- 把下一讲或作业交出去
- 时间不够就停：`剩下这个部分呢，我想是讲不完了，也许我们先来回答一下同学的问题`
- 2021：`我们十分钟以后再回来`

完整讲稿可以比他更干净地收，但最后一句仍应是课核，不是口号。

## 年份手感

| | 2021 | 2024 | 2025 |
|--|------|------|------|
| 开场 | 接上周、助教、休息 | 故事/反话 + 围栏 | 「一堂课搞懂」+ 日常平台 |
| 确认 | `对不对` `有没有` 较多 | 中等 | 较少 |
| 梗 | 较多，而且常声明「和今天没有关系」 | 可以整段当钩子 | 更克制，机制页可以完全没梗 |
| 术语 | 嘴里直接英文专名 | 中英夹，一条比喻养完整段 | 人话课核反复回声 |

写 2025 风讲稿：仪式开场 + 围栏 + 把它想成 + 课核回声。不要为了「像 2021」每分钟问一次对不对。不要为了「像 2025」把接龙 / 咒语写进无关课题。
