# 反模式

踩到就改。上一版 skill 漏了「空 / 糊 / 潦草 / 闷」，那些比用错配色更常见。这一版对照 2025 原件后又收了自制坐标当机制、贴纸游行。再下一层是 **AI 导播腔**：舞台指示、复述黄条、否定式口号。清单在 [humanize-classroom.md](humanize-classroom.md)。

## 一看就是别人

- 每页三张圆角卡片 + 图标圆圈（咨询公司盘，不是他的淡彩步骤块）
- 标题下彩色强调线、Midnight Executive、青绿品牌盘
- 内容页满版风景、页眉 Logo、页脚机密
- Nature 组会风：页上是论文章节名、幽默为零
- 把 2024 满版 AI 图封面或 2021 4:3 Calibri 英文底混进 2025 黑底「一堂课搞懂」

## 工作表味

- 把机制的资料行 / Loss 行装进 `a:tbl`（05/03 原件零表；合法只有 B2 2×3 方法目录和格子图）
- B2 表里填满数字（格子应是 `……`）
- 资料流用胖 `rightArrow` chevron（BBO L01 有 36 个）。默认是 2.5–3.5 pt 直线 + triangle 尾；sysDot 旁白
- 在 E 页用无脸灰盒代替 x/f/y（架构页灰神经元合法，p62）
- 公式黑白一坨，没有 w 蓝 b 红、没有红点线框
- 文字全黑，没有蓝=做法、红=关键的色义
- Office 图表当机制讲解而不是证据

## 自制坐标当机制（和空标题页分开打）

- **失败：** 自制 2D 轴 + 几个点，当成算法机制的主角（用坐标图代替盒子 / 箭头 / 一笔数）。反例：BBO L08 p8 讲 DE 变异。
- **可以：** 图是 observation / 证据——ChatGPT 截图、SGD 路径热图、真 UI、论文图。分布机制的主角是**椭圆状的云**；轴若有，只做淡底。
- 机制仍用淡彩块或贴纸资料流 + 当场一个算出来的数，并且把那个东西画出来。

## 空、糊、潦草、闷（优先打）

- **空标题页：** 机制页只有标题，或整页低到连主张都没有。约 40 字只防这一条。稀疏拍 2–8 个形状合法；机制/公式页通常 25–60
- 把 20 分钟机制课做成 24 张中等吉祥物页（应是 50–85 页疏密混排）
- 每页都倒一条底栏 caption（已有点线旁白就不要）。底栏若有，是一句主张，不是复盘
- 问句钩下面什么都没有
- 隐喻没有「日常物 → 技术对象」图例
- 盖住标题后，看不出这页在主张什么
- 无标注折线 / 无标注火柴人 / 手绘海岸冒充函数
- 「示意」当图画可以乱的借口
- 声称「误差高 / 范围小」但页上没有任何数或不等式
- 钩子是抽象风景 / 图库山水，不是听众正在过的场面
- 用复制递增把一张空页拉成四张；或只改口播
- XML 里 `cx`/`cy` 为负（PowerPoint 会报「内容有问题」）

## 贴纸游行 / 过密（和空页分开打）

- 一页同时上场手电筒 + 文件夹 + 旗 + 多行标签（BBO L01 s08 过密）
- 给 file / flag / flashlight / box 画笑脸（原件是物体图标：PPT 文件没脸，机器人胸口写 AI）
- 要求每张机制页都嵌 `robot-f.png`（43/84 的 BasicML 零图）
- 同一资料图标三行都同色
- 把整条 path-cost 塞进一页；或公开仓只有 `ruler.png` 时不补目录就开画

## 叙事错了

- 没有一条贯穿隐喻，或有三条
- 开场先定义再进入例子
- 迷因删掉不影响理解；流行文化做成主题而不是图上的一张抠图
- 一页推进三个互不相关的念头
- 「总结」写成 Key Takeaways 子弹

## 文字错了

- 页上出现完整段落
- 专名被译成日常汉语还当正文
- 全英文（除非用户要 2021）
- 参考文献做成最后三页列表
- 默认封面把课题涂黄（那是变体 B）；封面用 28–36 pt 或黄 `#FFD400`（封面 72–96 pt，黄 `#FFFF00`）
- 变体 B 加右下黄名（p2 无 byline）；变体 C 把署名做成右下黄字（06 是白、左下）

## 只点名不画 / 公式墙 / 死白（和空标题页分开打）

反例（描述，不入库）：

- **六点 vs 参数页：** 左 2×3 点盒、右 μσC 三根彩条，底边约 40% 空白。条里灰色「n=2 个数」贴在芯片地板上。右列标题写「下一拍只带这些」（导播腔）。没有云，只有胶囊。
- **核心公式墙：** 采样 / 评估排序 / 更新 / 步长启发式四段字，没有分布的样子。
- **σ CSA 页：** 两个巨大淡彩盒，算术浮在盒上半，每个盒底空掉三分之一。标题是主张，页上没有缩小的云。

- 搜索分布只用 μ σ C 彩胶囊，不画椭圆云
- 架构课用层名子弹代替结构图
- 对比页只摆两列说明，点和云不在同一页
- 一页叠满公式、没有图。拆成「一图 + 一笔数」
- 教学页底边 25%+ 空着，或 2.45 寸盒子只装三行。对面：字墙没气口（拆页，不缩字）
- 芯片内数字 / 二次标签贴地板，没有垂直居中
- 标签 bbox 吻上另一个形状（先删标签）

细则：[diagrams-required.md](diagrams-required.md)。

## 舞台指示 / AI 复盘（和空标题页分开打）

反例（描述，不入库）：一份 CMA-ES 均值更新页。顶上 μ / σ / C 三盒，μ 红描边；μ 下写「本页算完」，σ / C 下写「下一步」；「本页算完」楔进蓝色演算块；橙条「不去最好的 A」；底栏黄条「笑点不是 1 加错。圆心去三个精英的中心，不是旗子 A。σ 和 C 还没动。」页上没画旗。

- `本页算完` / `本页在干什么` / `本页做完` / `下一步` / `接下来会` / `接下来算` / `接下来动 σ 和 C`
- 没用到的参数盒下写状态。没算的盒：拿掉或静默，红描边就够
- 把标签塞进两层块之间的 8 pt 缝。盒相交是失败，即使字「有帮助」——先删标签，不要缩字号
- 复述黄条：`笑点不是…` / `笑点是…` / `关键不是…而是…`；把本页算术再讲一遍；`这页算完 X，下页算 Y`
- 否定式口号：`不是 X，是 Y` / `不去最好的 A`。对比用两个数
- `关键是：` `要点：` `核心思想：` `笑点是：`
- 填充：`值得注意的是` `需要强调的是` `总结一下` `接下来我们看看` `这里有三个要点`
- 比喻要第二句才懂，或物件没画（`旗子 A0`、螺丝是步长）。一拍测试不过就删比喻
- 同一点循环叫 精英 / 旗子 / 最好的人 / 第一名

## 口播错了

- 对着空页讲故事，页上却没有他嘴上说的那笔数
- 首先、其次、综上所述
- 一上来定义，没有「是什么意思呢 / 把它想成」
- 没有教室仪式
- 连续三分钟段子
- 用隐喻躲开公式
- 伪造「老师说过」
- notes 写成「本页说明 xxx」或导播词

## 技术诚实

- 示意数字写成真实实验
- 暗示听完就能做出做不到的产品

[ ] 旁白是 sysDot，不是 dash
[ ] 不是在 E 页用灰盒代替 x/f/y；也没有贴纸游行 / 笑脸图标
[ ] 公式逐项上色（w 蓝 b 红），第一式有红点线框
[ ] 盖住标题，图仍能说出主张

[ ] 机制页有至少一笔算出来的数
[ ] 钩子是听众正在过的场面
[ ] 复制递增是五种合法动作之一
[ ] 机制课有同一组三步块走三页
