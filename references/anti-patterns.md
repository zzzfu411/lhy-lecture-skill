# 反模式

踩到就改。上一版 skill 漏了「空 / 糊 / 潦草 / 闷」，那些比用错配色更常见。

## 一看就是别人

- 每页三张圆角卡片 + 图标圆圈
- 标题下彩色强调线、Midnight Executive、青绿品牌盘
- 内容页满版风景、页眉 Logo、页脚机密
- Nature 组会风：页上是论文章节名、幽默为零

## 工作表味（第二常见的露馅）

- 机制页出现表格（他的机制页零表格；数字是浮动演算）
- 全页角色都是无脸灰盒子，没有机器人 / 文件图标 / emoji
- 公式黑白一坨，没有 w 蓝 b 红、没有红点线框
- 只有实线箭头，没有点线旁白箭头
- 文字全黑，没有蓝=做法、红=关键的色义
- Office 图表当主角而不是配角

## 空、糊、潦草、闷（优先打）

- 机制页只有标题，或整页低于约 40 字
- 问句钩下面什么都没有
- 隐喻没有「日常物 → 技术对象」图例
- 盖住标题后，看不出这页在主张什么
- 无标注折线 / 无标注火柴人 / 手绘海岸冒充函数
- 「示意」当图画可以乱的借口
- 声称「误差高 / 范围小」但页上没有任何数或不等式
- 钩子是抽象风景，不是听众正在过的场面
- 用复制递增把一张空页拉成四张
- XML 里 `cx`/`cy` 为负（PowerPoint 会报「内容有问题」）

## 叙事错了

- 没有一条贯穿隐喻，或有三条
- 开场先定义再进入例子
- 迷因删掉不影响理解
- 一页推进三个互不相关的念头
- 「总结」写成 Key Takeaways 子弹

## 文字错了

- 页上出现完整段落
- 专名被译成日常汉语还当正文
- 全英文（除非用户要 2021）
- 参考文献做成最后三页列表

## 口播错了

- 对着空页讲故事，页上却没有他嘴上说的那张表
- 首先、其次、综上所述
- 一上来定义，没有「是什么意思呢 / 把它想成」
- 没有教室仪式
- 连续三分钟段子
- 用隐喻躲开公式
- 伪造「老师说过」

## 技术诚实

- 示意数字写成真实实验
- 暗示听完就能做出做不到的产品

## 自检清单

```
[ ] 机制页零表格；数字是箭头旁的浮动演算
[ ] 有角色：机器人 / 文件图标 / emoji / 斜体变量，不全是灰盒子
[ ] 公式逐项上色（w 蓝 b 红），第一式有红点线框
[ ] 实线 = 资料流；点线 = 旁白提问，至少各一处
[ ] 盖住标题，图仍能说出主张
[ ] 有一行隐喻图例
[ ] 机制页有至少一笔算出来的数（演算式，不是光秃数字）
[ ] 钩子是听众正在过的场面；有失败者 + 不公平的数字
[ ] 复制递增的第一张已经完整；每页多一个看得见的零件
[ ] 内容页白底；红框 1–2 处/页；蓝字做法红字警告
[ ] 有「请注意 / 虽然实际上并非如此」
[ ] notes 带人看图算那一笔
[ ] 数字标了示意或来源为真
[ ] pptx 的 cx/cy 没有负数
[ ] 没有接龙/咒语等原课口号（除非就在讲那一课）
```
