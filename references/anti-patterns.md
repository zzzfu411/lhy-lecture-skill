# 反模式

踩到就改。上一版 skill 漏了「空 / 糊 / 潦草 / 闷」，那些比用错配色更常见。这一版对照 2025 原件后又收了两条：自制坐标当机制、贴纸游行。

## 一看就是别人

- 每页三张圆角卡片 + 图标圆圈（咨询公司盘，不是他的淡彩步骤块）
- 标题下彩色强调线、Midnight Executive、青绿品牌盘
- 内容页满版风景、页眉 Logo、页脚机密
- Nature 组会风：页上是论文章节名、幽默为零
- 把 2024 满版 AI 图封面或 2021 4:3 Calibri 英文底混进 2025 黑底「一堂课搞懂」

## 工作表味

- 把机制的资料行 / Loss 行 / 预测 vs 实际装进表格（金标准是 p11 浮动演算或 p42 盒下算式）
- 提问模板表里填满数字（`06-TrainingTip` p3 那种空表 / `……` 才合法）
- 机制页**每个**角色都是无脸灰盒（回忆 IO 管线用彩色圆角块可以，见 BasicML p9）
- 公式黑白一坨，没有 w 蓝 b 红、没有红点线框
- 文字全黑，没有蓝=做法、红=关键的色义
- Office 图表当机制讲解而不是证据

## 自制坐标当机制（和空标题页分开打）

- **失败：** 自制 2D 轴 + 几个点，当成算法机制的主角（用坐标图代替盒子 / 箭头 / 一笔数）。反例：BBO L08 p8 讲 DE 变异。
- **可以：** 图是 observation / 证据——ChatGPT 截图、SGD 路径热图、真 UI、论文图。
- 机制仍用淡彩块或贴纸资料流 + 当场一个算出来的数。

## 空、糊、潦草、闷（优先打）

- **空标题页：** 机制页只有标题，或整页低到连主张都没有。约 40 字是地板，不是目标；三盒 + 一笔数就够，不要为了凑字塞满
- 问句钩下面什么都没有
- 隐喻没有「日常物 → 技术对象」图例
- 盖住标题后，看不出这页在主张什么
- 无标注折线 / 无标注火柴人 / 手绘海岸冒充函数
- 「示意」当图画可以乱的借口
- 声称「误差高 / 范围小」但页上没有任何数或不等式
- 钩子是抽象风景 / 图库山水，不是听众正在过的场面
- 用复制递增把一张空页拉成四张；或只改口播
- XML 里 `cx`/`cy` 为负（PowerPoint 会报「内容有问题」）

## 贴纸游行 / 过密（和空页分开打）

- 一页同时上场手电筒 + 文件夹 + 旗 + 多行标签（BBO L01 s08 过密：2025 原件机制页通常 1–3 种角色，或零贴纸）
- 要求每张机制页都嵌 `robot-f.png` + `ppt-file.png`（原件许多金页零贴纸，如 BasicML p42、LLMunderstand p5）
- 同一资料图标三行都同色（原件按行重着色）
- 把整条 path-cost 塞进一页，不留白

## 叙事错了

- 没有一条贯穿隐喻，或有三条
- 开场先定义再进入例子
- 迷因删掉不影响理解；流行文化做成主题而不是图上的一张抠图
- 一页推进三个互不相关的念头
- 「总结」写成 Key Takeaways 子弹

## 文字错了

- 页上出现完整段落
- 专名被译成日常汉语还当正文
- 全英文（除非用户要 2021）
- 参考文献做成最后三页列表
- 默认封面把课题涂黄（那是变体 B，不是 2025 默认品牌）

## 口播错了

- 对着空页讲故事，页上却没有他嘴上说的那笔数
- 首先、其次、综上所述
- 一上来定义，没有「是什么意思呢 / 把它想成」
- 没有教室仪式
- 连续三分钟段子
- 用隐喻躲开公式
- 伪造「老师说过」

## 技术诚实

- 示意数字写成真实实验
- 暗示听完就能做出做不到的产品

## 自检清单

```
[ ] 机制数字不在表格里（提问模板表可以空着；课程规划表可以）
[ ] 不是每个角色都是灰盒；也没有贴纸游行
[ ] 公式逐项上色（w 蓝 b 红），第一式有红点线框
[ ] 盖住标题，图仍能说出主张
[ ] 有一行隐喻图例
[ ] 机制页有至少一笔算出来的数（演算式，不是光秃数字）
[ ] 钩子是听众正在过的场面（半条流 / 点线缺口 / 教室漫画）
[ ] 复制递增是三种合法动作之一；不是空页、不是只改 notes
[ ] 默认封面：标题全白，黄只给右下署名
[ ] 没有自制坐标当机制；证据图可以留
[ ] 内容页白底；红框 / 红内描边 1–2 处/页
[ ] 有「请注意 / 虽然实际上并非如此」
[ ] notes 带人看图算那一笔
[ ] 数字标了示意或来源为真
[ ] pptx 的 cx/cy 没有负数
[ ] 没有把接龙/咒语/宝可梦当必用风格
[ ] 没有混进 2024 AI 封面或 2021 4:3 英文底
```
