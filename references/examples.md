# 短例子

先交「课核 + 图例 + 节拍 + 主图是什么 + 页序列」，再画页。下面示范**页上要有什么**，不要只抄题目。

## 例：过拟合（约 25 分钟）

**课核：** 训练资料上可以完美，换一张纸就不会。

**隐喻图例：**

| 日常 | 技术 |
|------|------|
| 驾训场墙上的贴纸 | 只在训练集成立的规则 |
| 场内满分 | 训练 Loss ≈ 0 |
| 路考撞护栏 | 测试误差高 |

**主图：** 一张散点。先只有训练点 + 疯狂穿过的曲线；下一页加上测试点掉在外面；旁注两个数：训练误差 0.01 / 测试误差 2.4（示意）。

**节拍：** 贴纸学员（正在考驾照的场面）→ 场内满分的数 → 换一张纸 → 命名 overfitting → 对照 bias（抽屉太小，训练误差也高）→ 不推 VC → 作业 public/private。

**页上不要：** 只有「这个学员会开车吗？」六个字。至少要有场内成绩表或那张散点。

## 例：bias（约 20 分钟）

**课核：** 能用的函数太少，再认真也对不齐资料。

**隐喻图例：**

| 日常 | 技术 |
|------|------|
| 只用直线从页数猜还要讲多久 | y = b + wx |
| 页数加倍、时间加不了一倍 | 真实关系是弯的 |
| 80 页还预测要讲 100 分钟 | 训练误差下不去 |

**主图：** 三行浮动演算——`📄10页 → f → 预测 17 ⋯ (18−17)²=1 ⋯ 实际 18`，逐行加到 80 页那行 `(58−101)²` 爆炸，点线框圈住演算列。**不是表格。**

**失败者：** 助教很认真地拟合，不是没算，是只准用直线。

不要用无标注海岸折线冒充主图，也不要把数字装进表格。
