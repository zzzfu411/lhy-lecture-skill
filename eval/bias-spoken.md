# 口播（v3，对照 17 页）

[封面] 好，那我们就开始上课吧。今天只讲一件事：有时候不是你算得不够认真，是你能用的函式太少。

[80 页还要讲多久] 你现在就坐在教室里。80 页，还要讲多久？你心里已经有一个函式在跑了。

[把问题画出来] 页数进去，分钟出来。输出是数字，这叫 Regression。问题只剩：f 怎么来？

[抽屉里只有一条直线] 蓝色的 w、红色的 b，是助教仅有的两个旋钮。下面那些带平方的才弯得起来——今天抽屉锁住。

[对答案 ×3] 第一笔：直线说 17，实际 18，平方差 1。第二笔差 9。第三笔：直线说 101，实际 58，(58−101)²，1849。红框圈住：不是没认真，是尺子太直。

[课核 + 图例] 抽屉里只有直线，资料后半是弯的，训练 Loss 就下不去。这不是没训练够，是模型太笨。

[bias 是什么意思呢] 先停，你已经有 1849 了。把它想成：能找的函式太少。训练的时候就露馅，不用等考试。

[判断树] 以后 Loss 下不去照这棵树走：先看训练资料。训练就大，往左——bias 或 optimization。训练小测试大，才是 overfitting。都小，😊。

[请注意] 数字全是示意，VC 维不推。但判断顺序是真的。

[步骤 3+1 ×2] bias 是步骤二的病。红框挪到步骤三看——它已经尽力了，病根在上一步。

[当场算] A 一二、C 三三拉直线，x=2 线上是 3.5，资料是 5。怎么转都差。微型 bias。

[作业接口] 训练 Loss 高 → 先怀疑抽屉，别先怪学习率。

[回声 / 停] 还是那一句：能用的函式太少，再认真也对不齐。只是现在它有名字、有判断树、有解法方向。告一个段落。
